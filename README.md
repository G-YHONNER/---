# 🌹 Rosa de 24 Colores — Para ti, Dianna Marisol

Una rosa CSS animada con 24 colores diferentes, estrellas, luciérnagas y efectos de partículas. Hecha con amor. 💕

## ✨ Características

- 🎨 **24 colores** — Toca o haz clic para cambiar el color de la rosa
- 🌟 Estrellas titilantes y estrellas fugaces en el fondo
- 🌟 Luciérnagas mágicas que flotan hacia arriba
- 🌸 Pétalos cayendo animados a 60/120Hz
- ✨ Destellos al interactuar
- 🖱️ Rastro de polvo de hadas al mover el mouse
- 📱 Funciona en móvil y escritorio

## 🕹️ Controles

| Acción | Resultado |
|---|---|
| Clic en la rosa | Siguiente color |
| Clic lado izquierdo | Color anterior |
| Clic lado derecho | Siguiente color |
| Tecla ← / → | Cambiar color |
| Mover mouse | Rastro mágico |

Abre `index.html` en cualquier navegador moderno. No requiere servidor ni dependencias.
